#  Loja Arraial

Um sistema em Python desenvolvido para o gerenciamento de vendas, produtos e estoque de uma loja com a temática de Festa Junina / Arraial. O projeto utiliza o terminal como interface e possui persistência de dados.

---

##  Funcionalidades

*   **Cadastro de Produtos:** Adicione novos itens ao estoque (ex: comidas típicas, adereços, bebidas).
*   **Gerenciamento de Estoque (CRUD):** Listar, atualizar preços/quantidades e remover produtos.
*   **Sistema de Vendas:** Registrar compras de clientes com atualização automática do estoque.
*   **Relatórios/Dados:** Visualização clara das informações cadastradas no sistema.

---

##  Estrutura do Projeto

O projeto está organizado da seguinte forma dentro do repositório:

*   `projeto_temporario/` (ou o nome da pasta que você escolheu)
    *   `main.py`: Ponto de partida do sistema (menu principal).
    *   `crud.py`: Funções de Criação, Leitura, Atualização e Deleção de produtos.
    *   `dados.py`: Responsável pelo armazenamento e manipulação dos dados/arquivos.
    *   `utils.py`: Funções utilitárias e auxiliares do sistema.
